# ギャル秘書 — macOS prototype

実写風の成人ギャル秘書が待機し、スマホで口元を隠して音声応答する試作アプリです。「こっち来て」でカメラに近づき、ウインクと投げキスをして席へ戻ります。

## できること

- 待機ループ、スマホを取る動作、口元を隠した通話ループ、通話終了、ウインク・投げキス。
- 文字入力からGeminiの返答と日本語AI音声を生成。
- Mac内の日本語音声認識で文字入力。録音終了後に内容を確認して「送信」。
- 「ウインク」「投げキス」「こっち来て」を含む依頼では、音声返答後にリアクションを再生。
- プレビューウインドウとデスクトップ背面表示の切り替え。常時録音はしません。

## 起動

macOS 13以降、Xcode Command Line Tools、Python 3、Gemini APIキーが必要です。証明書エラーがあるPython環境では、信頼されたCAを設定するか `certifi` を利用します。

`GEMINI_API_KEY` が設定済みのターミナルから、このディレクトリの `start.command` を実行してください。起動時にアプリをビルドします。終了時はターミナルでControl-Cを押すと音声サーバーを停止できます。

ビルド済みアプリは `build/GyaruSecretary.app`。音声サーバーなしでも動画プレビューと「こっち来て」は利用できます。音声認識を使う場合はmacOSのマイク・音声認識許可が必要です。日本語の端末内音声認識が使えないMacでは文字入力を使用します。

操作パネルの「入力マイク」で利用するマイクを選べます。この選択はアプリだけに適用され、Mac全体の既定入力は変更しません。このMacの既定入力はBlackHole 2ch（仮想入力）です。人の声を直接拾う場合は、接続中のiPhoneマイクなどを選択してください。

操作パネル右上の「映像を表示」、または「表示 → 映像を見る」（Command-1）で映像を前面に呼び戻せます。映像を閉じた場合や最小化した場合も復帰します。「表示 → 操作パネルを表示」（Command-2）は通常モードでは映像も一緒に表示します。映像と操作パネルは同じデスクトップに表示され、映像が画面外にある場合は操作パネル側の画面内に戻します。デスクトップモードから「映像を表示」を押すと通常のウインドウ表示に戻ります。アプリを終了する場合はメニューの「終了」（Command-Q）を使います。BlackHoleを使った検証用メニューもあります。これは同梱サンプル音声を仮想入力に流すテストで、自動送信はしません。

## 音声の処理

音声認識はMac内に限定します。「送信」を押すと会話文と直近最大12発言をGoogle Geminiへ送り、返答と合成音声を取得します。会話履歴はアプリのメモリ内のみ。Google側の取り扱いは利用するAPI契約に従います。

APIキーはサーバーの環境変数から読み、アプリ・リポジトリには保存しません。サーバーはlocalhostのみに接続を受け付け、実行ごとのトークンで認証します。トークンは `~/Library/Application Support/GyaruSecretary/runtime.json` に保存します。ブラウザからの呼び出しは受け付けません。

既定値は会話 `gemini-2.5-flash`、音声 `gemini-2.5-flash-preview-tts`、声 `Kore`。環境変数 `GYARU_CHAT_MODEL`、`GYARU_TTS_MODEL`、`GYARU_VOICE` で変更できます。生成のたびにAPI利用量が発生します。

## 素材

- `assets/master.png`: 人物と部屋の基準画像。
- `assets/idle.mp4`: Higgsfield生成の待機動画、5秒。
- `assets/phone.mp4`: スマホを取る・応対・戻す動画、15秒。
- `assets/playful.mp4`: 近づく・ウインク・投げキス・戻る動画、15秒。
- `assets/idle-loop.mp4` / `phone-loop.mp4`: 継ぎ目をフェード処理した無音ループ。
- `assets/phone-voice-demo.mp4`: 固定台詞を使った視聴用デモ。ライブ会話の録画ではありません。
- `assets/voice-sample.wav`: 6.53秒の日本語音声サンプル。
- `assets/clips.json`: 状態と動画の対応、再生区間。

アプリでは生成動画の音声をミュートし、合成音声を独立再生します。表示切り替えは次の映像フレームの準備完了を待ってフェードします。
