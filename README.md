# ギャル秘書

実写風のギャル秘書がデスクトップにいる、macOS用チャットアプリ。既存のGemini接続で会話し、動画はアイドリングを続けます。

## 現在の画面

- 会話履歴と複数行の入力欄を中心にしたチャット。
- Enterで送信、Shift + Enterで改行。日本語の変換中はEnterで送信しません。
- 自分の発言と秘書の返答を区別して表示。返答待ち、接続エラー、再送に対応。
- 右上の「…」に映像の表示／非表示、デスクトップ表示、チャットの最前面固定、新しいチャット、アプリ情報を集約。
- 音声対話とリアクションは保留。録音・音声生成・音声再生は行わず、会話中もアイドリング動画を再生。

## 起動

macOS 13以降、Xcode Command Line Tools、Python 3、Gemini APIキーが必要です。

`GEMINI_API_KEY` を環境変数に設定済みのターミナルから実行します。キーはソースや設定ファイルに書き込みません。

```bash
./start.command
```

起動時にアプリをビルドしてローカルの会話サーバーを開始します。ビルド済みアプリは `build/GyaruSecretary.app`。サーバー稼働中はアプリを終了・再起動しても利用できます。サーバーなしでも画面と動画は表示され、送信時は接続エラーと再送ボタンが表示されます。

アプリ終了はCommand-Q。サーバーを止める場合は起動したターミナルでControl-Cを押してください。

「表示 → 映像を表示」（Command-1）で閉じた映像や最小化した映像を呼び戻せます。「表示 → チャットを表示」（Command-2）でチャットを開きます。通常のチャットは他のウインドウを覆い続けません。必要なときだけ「…」から最前面に固定できます。

## 会話とデータ

- 会話相手はGemini。Codexなどの作業エージェント接続、検索、カレンダー、ファイル操作は未実装です。
- 送信した文章と直近6往復をGoogleへ送ります。会話履歴はアプリ内のメモリだけに保持し、アプリ終了時に消えます。
- 既定モデルは `gemini-2.5-flash`。環境変数 `GYARU_CHAT_MODEL` で変更できます。会話の送信にAPI利用量が発生します。
- キーはサーバーの環境変数から読みます。接続先はlocalhostのみ、実行ごとのトークンで認証し、ブラウザのOrigin付きリクエストを拒否します。
- 実行情報は `~/Library/Application Support/GyaruSecretary/runtime.json` に保存します。キーや会話本文は保存しません。
- 「返答の待機を止める」はアプリ側の待機を中止します。送信済みの外部処理や利用量は取り消せません。

## 構成

| フォルダ | 内容 |
| --- | --- |
| `native/` | SwiftUIのチャット画面、会話処理、AppKitのウインドウ、動画再生 |
| `server/voice.py` | 既存の会話・音声サーバー。現行アプリは `audio: false` のテキスト経路だけを使用 |
| `assets/` | 生成済み画像・動画・音声。保留中の素材も保存 |
| `tests/` | サーバーとネイティブ会話処理のテスト |
| `docs/` | 素材の生成記録・動作確認・移管記録 |
| `build/` | ローカルのビルド出力。Git管理対象外 |

旧音声プロトタイプは最初のコミット `f3c0b7d` に保存しています。音声APIを使う既存の試験経路は互換性を維持し、現行アプリからは呼び出しません。
