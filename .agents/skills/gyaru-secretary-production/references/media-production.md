# 素材生成と接続品質

以下のパスはリポジトリルートからの相対パス。

## 実績のある生成設定

Higgsfield の Kling 3.0、UIで1080p、音声OFF、Enhance OFF、Multi-shot OFF、固定カメラ。当時はログイン済みSafariで操作した。利用できるブラウザ・ログイン状態を確認し、現在の画面に基づいてComputer Useで操作する。過去の要素IDを流用しない。

送信前に開始・終了画像のサムネイル、尺、モデル、音声、公開設定、表示クレジットを確認する。自動公開はOFF。送信したら結果ID・状態を記録し、応答が不明でも重複送信せず履歴を確認する。ログイン・残高・生成失敗で進めない場合は原因を解消するまで追加生成を止める。購入・公開は別の明示依頼がある場合に限る。

過去の実績は10秒が15クレジット、15秒が22.5クレジット、着替え用6本で120。これは当時の記録であり、現在の価格・予算ではない。

## 通常衣装のアイドルと入力

`assets/base_shiro_gyaru.png` を開始・終了両方に指定した。中盤はモニター・スマホへ視線を向け、最後に同じ姿勢へ戻す。基準写真はカメラ目線なので、単に「同じ人のループ」ではカメラを見続けやすい。

- coffee：左のモニターを読みながらコーヒー。
- phone：スマホを見下ろして読み、スクロール。
- mouse：モニターを見る、マウス移動・クリック・スクロール。入力や挨拶は入れない。
- typing-playful / typing-annoyed：両手の実際の打鍵、モニターへ向けた表情。開始・終了は共通の基準姿勢。

15秒ループで冒頭1〜2秒の視線移動、最後2秒の姿勢復帰を指示した。実際の時間は生成結果で判断する。記録は `docs/idle-shiro-v2/README.md` と `production-record.json`。過去の専用手振り動画は現在のアイドルには含めない。

## 着替えシーケンス

全文プロンプトは `docs/outfit-change/prompts.md`、画像は同ディレクトリの `references/`。

| 動画 | 開始 | 終了 | 再生尺 |
|---|---|---|---:|
| exit | 通常衣装の基準画像 | empty.png | 10秒 |
| empty | empty.png | 同じ画像 | 7秒 |
| return | empty.png | seated.png | 10秒 |
| note | seated.png | note.png | 15秒 |
| work | note.png | working.png | 15秒 |
| idle / typing | working.png | 同じ画像 | 各15秒 |

exitは画面を読む→驚く→カメラを睨む→席を立って画面外へ。returnはすでに新衣装を着た状態で入室・着席する。noteは紙へ書いてから参照の文字とハートを見せる。workは付箋を置き、モニターへ向いて入力へ戻る。

**約10秒の不在は空席クリップだけの長さではない。** 今回はexitの空席約2.375秒＋静止画から作る空席7秒＋returnの空席約0.625秒＝約10秒。別の生成結果では実際に姿が消えた時刻と戻る時刻を見て挿入尺を計算する。

固定カメラ、同じ人物・衣服・手・机・部屋を維持する。音声、カット、ズーム、途中の衣服変形を入れない。今回のループは逆再生でつなぐ方式ではない。

## 保存と確認

原本は `assets/originals/<制作単位>/` に残す。通常の配布用動画は映像ストリームをコピーし、音声を除いてMP4 faststartを付ける。静止画から作る空席は他の素材に合わせてエンコードする。

```bash
ffmpeg -n -i ORIGINAL.mp4 -map 0:v:0 -c:v copy -an -movflags +faststart RUNTIME.mp4
```

過去の1080p生成は実際には1920×1076、24fps、10.041667秒または15.041667秒だった。再生境界は10秒・15秒。UIの解像度名や尺だけで判断せず、ffprobeと全編デコードで確認する。

中盤の動作・視線・文字・手をタイムライン画像で確認し、冒頭と再生境界直前のフレームを比較する。アイドル同士、アイドル→入力、入力→アイドル、通常衣装→exit、演出内の隣接クリップを含める。ピクセル差は補助資料で、動作の自然さや文字の読みやすさの保証ではない。

```bash
python3 scripts/verify-idle-media.py --manifest docs/idle-shiro-v2/all-clips.json --output docs/idle-shiro-v2
python3 scripts/verify-outfit-media.py --manifest assets/outfit-change.json
```

これらは同じレビュー先の画像・JSONを更新する。過去版と比較する場合は記録を先に別の制作ディレクトリへ分ける。

プロンプトを満たさなかった点も記録する。今回workは両手同時入力ではなく左手の打鍵＋右手マウスだったが、依頼の「キーボード入力」は見えた。最終承認済みの見え方を、プロンプトだけを根拠に失敗扱いしない。
